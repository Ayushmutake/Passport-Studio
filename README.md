# Passport-Studio
Browser-based passport photo print layout tool. Upload photos, auto-crop to exact passport size without stretching, and print or export

--PassPort Studio is a single-file, no-build web app for laying out passport and visa photos on print sheets. It supports multiple sizes (35×45, 51×51, 40×60, 25×35 mm) and sheets (A4, 4×6, 5×7). Photos are cropped to the exact ratio with adjustable zoom and position, and you can print directly or save a 300 DPI PNG. Everything runs locally in the browser, so photos never leave your device.
